Data-Driven Decision Dashboard: High-Volume Raw Data Analysis

Project Overview

This project demonstrates the transformation of large-scale, unstructured raw data (ranging from 8,000 to 90,000+ rows) into an interactive, stakeholder-ready Excel Dashboard. The goal was to take complex datasets and distill them into actionable insights using advanced Excel techniques, focusing on key performance indicators (KPIs) and data storytelling.

🛠 Features & Methodology

To handle the high volume of data and ensure the dashboard remained performant and insightful, I followed a rigorous data analysis workflow:

1. Data Cleaning & ETL (Extract, Transform, Load)

• Massive Dataset Management: Processed multiple datasets with row counts exceeding 90,000 entries.

• Data Integrity: Handled missing values, removed duplicates, and standardized formatting to ensure accuracy across all pivot calculations.

• Optimization: Structured the raw data into Excel Tables to allow for dynamic range updates.

2. Analytical Processing (The "Engine")

• Pivot Table Architecture: Utilized complex Pivot Tables to aggregate data across various dimensions (Time, Geography, Product Category, etc.).

• Custom Calculations: Created Calculated Fields and Items within Pivot Tables to derive specific business metrics not present in the raw data.

• Data Modeling: Established relationships between different data points to provide a multi-dimensional view of the performance.

3. Dashboard Design & Visualization

• Interactive Slicers: Implemented Slicers and Timelines to allow stakeholders to filter the entire dashboard by specific timeframes or categories with a single click.

• Stakeholder-Centric UI: Designed the layout to highlight top-level KPIs (Total Revenue, Growth %, etc.) at the top, followed by detailed trend analysis and categorical breakdowns.

• Conditional Formatting: Used data bars and color scales to provide immediate visual cues for performance outliers.

📈 Key Insights Addressed

The dashboard was designed to answer critical business questions for stakeholders, such as:

• What are the primary drivers of growth across the 90,000+ recorded transactions?

• Which specific segments are underperforming relative to the seasonal average?

• How do current trends compare against historical raw data benchmarks?

🚀 Technical Skills Demonstrated

• Advanced Excel: Pivot Tables, Slicers, Power Query (for data cleaning), and Dynamic Arrays.

• Data Visualisation: Chart selection (Trend lines, Bar charts, Gauges) and Dashboard UI/UX.

• Data Analysis: Trend spotting, anomaly detection, and statistical aggregation.
